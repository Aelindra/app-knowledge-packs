# 淘宝 综述

**定位**：阿里旗下综合电商（移动端为主力形态）。

> 风险边界：本条目仅为功能事实综述。淘宝属强风控账号型应用，自动化操作
> （下单/领券/签到类）不建议，购物支付环节应人工确认。

## 功能地图

- **购物主流程**：搜索 / 推荐流（猜你喜欢）→ 商品详情 → 购物车合并结算 → 支付（含先用后付）
- **88VIP**：会员体系；年费与淘气值挂钩（≥1000 分为 88 元/年，否则 888 元/年）；
  权益含优酷/淘票票等生态会员与购物券，**权益细则随年度调整**
  （如退货包运费自 2025-02 起对新周期用户改为限次）
- **淘金币**：任务/购物所得积分，结算抵扣
- **先用后付**：基于信用授信（芝麻信用）0 元下单，确认收货后自动扣款
- **逛逛**：底部内容社区入口（短视频/图文种草/直播）
- **淘宝直播**：直播电商入口
- **物流**：菜鸟裹裹打通（查件/寄取件/退换货上门取件）
- **客服**：App 内智能客服（小蜜）+ 人工
