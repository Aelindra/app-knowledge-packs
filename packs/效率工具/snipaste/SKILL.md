# Snipaste 综述

**定位**：截图 + 贴图双核工具（作者 Le Liu，免费版 + 专业版，专业版含滚动截图等）。
"贴图"（pin）= 把剪贴板中的图像作为置顶浮动图钉在桌面，是该工具的标志性功能。

## 核心流程

1. **截图**：F1 → 自动识别窗口/控件边缘选区 → 标注工具栏（箭头/马赛克/文字等）→ 复制 / 保存 / 贴图
2. **贴图**：F3（将剪贴板内容贴为置顶浮动图）→ 滚轮缩放、调透明度、鼠标穿透、另存
3. **取色**：截图过程中光标处实时显示像素 RGB/HEX 值，按 C 复制
4. **全局贴图管理**：Ctrl+F1 隐藏/显示所有贴图

## 快捷键体系

默认 F1（截图）/ F3（贴图）/ C（取色复制）/ Ctrl+F1（贴图总开关）；
全部可在「首选项 → 控制」自定义。

## 词表

贴图（pin）｜放大镜（选区时像素放大定位）｜首选项（偏好设置）

细节与完整快捷键以官方手册为准（见 sources.md）。
