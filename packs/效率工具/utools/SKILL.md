# uTools 综述

**定位**："一切皆插件"的效率平台（官网 u.tools）。本体只提供主输入框与插件运行时，
功能全部由插件提供（翻译/剪贴板/JSON 格式化/取色/本地程序启动等）。

## 核心流程

1. **呼出主输入框**：默认 Alt+Space → 输入关键字 → 命中插件/本地程序/文件 → 回车执行
2. **超级面板**：选中文件或文本后按**鼠标中键**呼出 → 按选中内容类型智能推荐插件动作
   （翻译、OCR、搜索等）
3. **插件安装**：插件中心在线安装；离线 .upx 包导入；开发者模式调试；分享链接/二维码
4. **账号体系**：登录后插件与配置跨设备同步（部分能力属会员）
